# Optical levitation project

 * **pylqg_project**
   - A good starting point is [pylqg_project/notebooks/levitated_optomechanics_LQG_1d.ipynb](https://github.com/phwl/levcontrol/blob/main/pylqg_project/notebooks/levitated_optomechanics_LQG_1d.ipynb) which is a tutorial explaining the idea in 1D.
   - The high-level DAC board design is in [pylqg_project/notebooks/AD3552R_four_channel_DAC_circuit_design_tutorial.ipynb](https://github.com/phwl/levcontrol/blob/main/pylqg_project/notebooks/AD3552R_four_channel_DAC_circuit_design_tutorial.ipynb) and the details [here](https://github.com/phwl/levcontrol/blob/main/ad3552r_dac/docs/AD3552R_DAC_Mezzanine_Design_Manual.docx)
   - A notebook to reproduce the paper is here [pylqg_project/notebooks/pylqg_tutorial.ipynb](https://github.com/phwl/levcontrol/blob/main/pylqg_project/notebooks/pylqg_tutorial.ipynb)
 * **LQGcontroller** - repository containing the code and artifacts accompanying the article: "FPGA-based LQG controller and hardware-in-the-loop simulator implementation for nanomechanical systems"
